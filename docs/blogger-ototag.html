音楽ファイルのタグ編集アプリ「OtoTag」を公開しました

音楽ファイルの曲名やアーティスト名がぐちゃぐちゃで困ったことはありませんか。

ファイル名は合っているのに、プレイヤーで表示される曲名が違う。

カバー画像が入っていなくて、一覧が寂しい。

そんな悩みを解決するために、タグ編集アプリ「OtoTag（おとタグ）」を作りました。

Android と Windows の両方で使える、無料のアプリです。

公開後も改良を続けていて、この記事も最新の内容に書き直しました。

OtoTag でできること

  • 曲名、アーティスト、アルバム、アルバムアーティスト、作曲者、ジャンル、年、トラック番号、ディスク番号、コメント、ISRC、歌詞まで編集できます。
  • カバー画像（ジャケット写真）を入れたり、差し替えたりできます。画像ファイルのほか、URL やクリップボードからも入れられます。
  • 対応形式は MP3、FLAC、M4A / MP4、OGG Vorbis、Opus、WAV、AIFF、DSF です。拡張子と中身が違うファイルも、中身を見分けて正しく扱います。
  • ボタンひとつでネット検索して、正しいタグとカバーを候補から選んで入れられます。タグが空っぽでも、ファイル名やフォルダ名から推測して検索できます。
  • 音の指紋で検索もできます（AcoustID。無料の個人 API キーが必要です）。
  • 歌詞も取得できます。同期歌詞は .lrc ファイルとして曲の横に保存できます。
  • 複数の曲を選んでまとめて編集したり、選んだ全曲に同じカバーを設定したりできます。
  • ファイル名の変更もできます。先頭のトラック番号を消すボタンもあります。
  • ジャンルは既定の60件に加えて、自分のジャンルを自由に追加・整理できます。
  • 変更前の状態にいつでも戻せるので、安心して試せます。

画面はこんな感じです

フォルダを選ぶと、中の音楽ファイルがカバー画像つきで一覧表示されます。

上のボタン行には「ジャンル」ボタンもあり、ジャンルの追加や整理がここからもできます。

曲の画像をタップするとその場で再生できるので、中身を確認しながら作業できます。

検索すると、このように候補がカバー画像つきで一覧表示されます。

結果は届いたものから順に出てくるので、全部の検索が終わるのを待たなくて大丈夫です。

前に選んだ候補は、次に同じ曲を検索したときに先に表示されます。

編集画面です。変更した欄は色が変わり、保存する前に変更点の一覧で確認できます。

ジャンルは「ジャンルを選ぶ」から選ぶほか、その場で「ジャンルを保存」を押して自分のジャンルに加えることもできます。

一括編集です。アーティスト、アルバム、アルバムアーティスト、作曲者、ジャンル、年、ディスクの7項目を、選んだ全曲にまとめて設定できます。

空欄にした項目は元のままになるので、1項目だけをまとめて直すこともできます。

検索が便利です

タグ付けで一番めんどうなのは、曲名やアーティスト名を手で打ち込む作業です。

OtoTag は、MusicBrainz、iTunes、Deezer、AnimeThemes、VGMdb、Audius、国立国会図書館サーチの7つのデータベースを検索して、候補を一覧で出してくれます。

あとは正しい候補をタップするだけです。カバー画像も一緒に取得できます。

使うデータベースは設定で切り替えられます。

候補が見つからないときは、タイトルだけ・アーティストだけで探し直すこともできます。

タグもファイル名も手がかりにならない曲は、音の指紋（AcoustID）で探せます。曲の音そのものから照合するので、思わぬ曲が見つかることがあります。

古いファイルで文字化けしているタグは、読み込み時に自動で直します。

歌詞も取れます

歌詞は LRCLIB、Lyrics.ovh、Musixmatch の3つから取得できます（Musixmatch は無料の個人 API キーが必要です）。

複数の結果が見つかったときは、並べて比べてから選べます。

LRCLIB の同期歌詞は .lrc ファイルで保存できるので、対応したプレイヤーでカラオケのように表示できます。

ジャンルの整理ができます

既定のジャンルは60件あります。アニソン、ゲーム、ボーカロイド、歌謡曲、演歌、シティポップなど、日本語のジャンルも入っています。

自分のジャンルは、ジャンルを選ぶ画面の一番上や、最初の画面の「ジャンル」ボタンから追加できます。

使わないジャンルは削除できます（押すときに確認が出ます）。

削除したジャンルは専用の画面に残っていて、「戻す」や一番上の「全て戻す」でいつでも復活できます。

自分で追加したジャンルは、その画面で完全に削除することもできます。

アニソンにも強いです

アニメの主題歌は、一般のデータベースでは見つかりにくいことがあります。

そこで OtoTag は、アニメの OP / ED 専門データベース「AnimeThemes」にも対応しました。

候補を選ぶと、アニメ名がアルバムに、OP1 や ED2 といった主題歌の種別がコメントに自動で入ります。

アニソンの整理がぐっと楽になります。

まとめて整理もできます

一覧は、タグなし・カバーなし・エラー・タイトルなしなど、項目ごとに絞り込めます。並び替えは昇順・降順の切り替えつきです。

チェックの状態に合わせて切り替わる「全選択／全解除」ボタンもあります。

よく使うフォルダはピン留めでき、最近開いたフォルダも履歴からすぐ開けます。サブフォルダを含めるかどうかも選べます。

改名のとき、同じ名前のファイルが既にあると、理由を表示して止まります。知らないうちに失敗していた、ということがありません。

安心ポイント

  • タグを変更する前に、必ず自動でバックアップを取ります（タグとカバーの控えなので、容量は小さめです）。
  • 間違えても「戻す」で復元できます。
  • 検索結果を自動で確定することはありません。必ず自分で候補を選ぶ方式です。
  • 画面は12言語対応で、初期値は端末の言語です。ダークモードもあります。
  • アプリ内に使い方のページと更新履歴があり、新しい版は自動更新で入れられます。

音楽ライブラリの整理に、ぜひ使ってみてください。
